# King Air Kev

A portrait, touch-controlled 16-bit-style arcade game made for iPhone.

## Play

Open `index.html` through GitHub Pages or any static web host. On iPhone, use Safari's **Share → Add to Home Screen** to install it like an app.

## Game

- Three difficulty modes: Training, Line Check and Kev Mode
- Three timed levels: runway birds, storm climb and city approach
- Left/right touch controls
- Three-hit damage system, scoring, sound effects and retro music
- Offline-capable PWA

No build tools or external assets are required.
